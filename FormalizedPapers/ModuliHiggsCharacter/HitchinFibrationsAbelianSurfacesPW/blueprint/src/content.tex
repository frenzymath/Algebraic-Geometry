TeX are indexed in the workspace manifest; see \href{../../../../../references/hitchin-fibrations-abelian-surfaces-pw/}
{\texttt{hitchin-fibrations-abelian-surfaces-pw}} and \href{https://arxiv.org/abs/1909.11885}{the arXiv record}.

Each chapter file below corresponds to one source-level section (with a
front-matter chapter when needed). The source text is retained verbatim apart
from replacing section headings by blueprint chapters, expanding
\texttt{\\input} inclusions, and adding \texttt{\source}/\texttt{\notready}
provenance annotations to source nodes. The provenance remark at the start of
each chapter is marked \notready because no Lean declaration has yet been
checked for that source material.
