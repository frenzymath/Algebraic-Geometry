\chapter*{About This Blueprint}
This blueprint follows Athanasios Papaioannou, \emph{An algebraic approach to
the Riemann--Roch theorem and the arithmetic theory of function fields}.  The
source PDF is available
\href{http://www.fen.bilkent.edu.tr/~franz/mat/Riemann-Roch.pdf}{from the
author's host institution}.

It retains the definitions, hypotheses, unnumbered assertions, numbered
results, and proof arguments in the mathematical chapters.  Examples,
exercises, bibliography, index material, and historical or pedagogical prose
are omitted.  The \emph{dcref} value records the printed source number and
\emph{source} records the PDF page.
