\chapter*{About This Blueprint}

This project follows J. S. Milne, \emph{Abelian Varieties}, course notes,
version 2.00 (2008). The source PDF is available from the author's website
\href{https://www.jmilne.org/math/CourseNotes/AV.pdf}{here}.

The notes develop the geometry and arithmetic of abelian varieties: the
theorem of the cube, duality, isogenies, polarizations, Tate modules and
finite-field theory, Jacobian varieties, and the finiteness theorems leading
to Faltings's proof of the Mordell conjecture.

This blueprint is a source-near transcription, not a replacement for the notes.
It retains the definitions, constructions, statements, dependencies, and proof
arguments needed for formalization while omitting exercises, examples, and
historical or pedagogical prose.
\textbf{It should be read alongside the original source PDF}, which supplies
the full exposition, context, and qualifications. The \emph{dcref} metadata
records where each item occurs in Milne's notes.

The current blueprint covers the mathematical sections of Chapters I--IV:
geometry, arithmetic, Jacobian varieties, and finiteness theorems.
