Algebraic Geometry is a source-faithful formalization workspace.

The repository connects carefully transcribed mathematical sources with dependency tracking and a future Lean formalization layer. The graph is organized for comparison, reuse, and gradual formal verification.

Source library

The Stacks Project is imported through Parts 1-8, covering 109 chapter blueprints. The reference shelf also includes Mumford and Milne on abelian varieties and Hartshorne on algebraic geometry, curves, and cohomology.

Formalization direction

Shared infrastructure is kept separate from source material. The Algebraic Jacobian Challenge is the flagship direction, with the abelian-variety and curve references providing the surrounding theory.

Current snapshot

The manifest registers 11 active projects: eight Stacks parts and three companion references. The workspace graph currently indexes more than 17,000 source statements; Lean declarations are added incrementally and are never claimed before they exist.

Repository contains the blueprints, provenance records, shared infrastructure, and reproducible workspace configuration.
